# Bounded investigation agent

The adaptive workflow uses the pinned official **Qwen2.5-1.5B-Instruct** model locally. It reads numeric B-Free observations and chooses the next available tool. It receives neither image pixels nor filenames, embedded text, ground-truth labels or arbitrary user instructions. The existing fixed experiment remains a separate, reproducible workflow.

## Execution contract

The application first normalizes the image, records its dimensions and hashes, and makes one required B-Free measurement. This bootstrap is disclosed as mandatory; it is not an LLM decision. Thereafter the language model can select:

- One JPEG quality-85 pass.
- Three cumulative JPEG quality-85 passes.
- One resize to 90% of the original dimensions.
- Three cumulative rounds of 90% resizing followed by quality-95 JPEG.
- An optional TruFor scan of the normalized original for local-manipulation evidence.
- Finish.

Each perturbation branch starts from the normalized original. Within a repeated branch, each round uses the previous decoded image. A branch consumes one detector-tool call because only its final image is scored. The default budget is four model-tool calls, including the mandatory original; the interface accepts two to six. Every attempted tool call consumes budget, including failed calls. No action can be selected twice. TruFor is absent from the action list when it is disabled or unconfigured. Cancellation is checked between calls; the currently running model call completes first. TruFor has a ten-minute subprocess limit; this is not a global investigation time guarantee.

## What the language model actually does

At every decision, the prompt contains the fixed policy, observed evidence and a numbered list of currently allowed actions. The official tokenizer encodes each numbered choice as one token. A forward pass scores those tokens, and the highest-logit allowed action is selected. This is constrained language-model action selection, not free-form tool-call generation or a hardcoded score-routing loop. The policy instructs efficient investigation but does not force any particular perturbation after the bootstrap.

The action softmax is recorded for audit as relative model preference **among offered actions**. It is not a calibrated confidence value. Action ordering is fixed; positional bias has not been measured. The trace records the offered actions, observations seen, selected action, input-token count, prompt/policy hashes, model-file hashes, revision, execution device and duration. It does not invent a model rationale. The dispatcher rejects any action outside the allowlist and has no shell, file-editing or network tool exposed to the planner.

Invalid logits or unavailable weights stop the adaptive investigation with an explicit error. There is no automatic substitution of the rule policy. The rule policy exists solely as a named comparison in the agent evaluation.

## Grounded reporting

Every measurement receives an evidence ID (E1, E2, ...). A deterministic report builder computes score ranges, threshold changes, and measured-test counts directly from successful observations, and attaches evidence IDs to its factual statements. Failed measurements remain missing. If no perturbation succeeds, the report says robustness evidence is insufficient. The final narrative is not generated by the language model.

B-Free measures AI-generation evidence; TruFor measures local-manipulation evidence and produces anomaly/reliability maps. Their scores are never averaged. Low scores do not prove authenticity, elevated scores do not prove generation, and correlated derivatives are not independent corroboration. The UI shows adaptive tests as separate branches rather than suggesting that the chosen sequence is one cumulative trajectory.

- Runtime: existing Transformers/PyTorch environment, local-files-only, remote model code disabled, float32. The verified MPS runtime produced nonfinite FP16 logits, so FP16 is not used. That failed integration run remains recorded separately.

Install on a configured model environment with `.venv/bin/python scripts/install-planner.py`. Set `FORENSICS_PLANNER_DEVICE=cpu` to force CPU; default `auto` selects MPS when available. The checkpoint is checked against the pinned digest before loading. No uploaded image or observation is sent to a remote service.

## Evaluation boundaries

`forensics.agent_evaluation` freezes a 24-source subset comprising three matched real/generated test groups per generator, selected by a fixed hash before policy scoring. It compares a four-call fixed sequence, an explicit rule baseline, and the local language model using the same recorded B-Free observations and four-call budget. TruFor is disabled for this matched replay because the benchmark has no regional results.

The reference outcome is whether **any of the four available perturbation tests changes the original threshold decision**. Discovery recall measures how many such cases a bounded policy finds. It does not measure image-authenticity accuracy. Replay saves redundant neural calls and measures policy selection; its wall time is not end-to-end inference latency. Real browser integrations are recorded separately.

Budget compliance, action validity and evidence-reference validity are structural checks. They do not establish human-rated explanation quality. This small descriptive comparison supports no statistical claim that the LLM improves detection. The original broader study would require more images, new generator families, external data, policy repetitions and a separate evaluation of regional-map usefulness.
